# リライト計画

## 元記事の検索意図

- 「セックス アプリ」「セックスできるアプリ」「セフレ アプリ」などで検索する成人読者に対して、セックスにつながる可能性のある出会い系アプリ・マッチングアプリを比較し、安全に選ぶ判断材料を提供する。
- 読者は、即会い・セフレ探し・大人の出会いに向くアプリ、避けるべき危険、身バレや個人情報流出を防ぐ方法を知りたい。

  - 年齢層が近いユーザーが多いか

  - 公的な届出をしているアプリを選ぶ

## 絶対に残すべきH2/H3・削除してはいけない見出し

- 元記事のH2/H3は検索意図に直結しているため、本文のない空見出しを作らず維持する。
- 特に「おすすめ10選」「選び方」「注意点」「よくある質問」「まとめ」はCV導線と安全性の両面で重要なため削除しない。

## 追加・補強方針

- 冒頭文に「セックス アプリ」「セックスできるアプリ」「セフレ アプリ」などの検索意図を自然に反映する。
- 比較表は `npm run table -- articles/sample-article` で自動生成し、「この記事でわかること」のcapbox外に挿入する。既存のカード型比較は残しつつ、テーブル形式の比較表は1回のみ設置する。
- 選び方・注意点・FAQ・まとめ系H3は比較表候補から除外する。
- 「追加確認が必要」が半数以上になる場合は比較表を作成せず、理由をchange-logに記録する。
- 外部リンクは見出し内に入れず、法令・年齢確認・個人情報・安全性に関係する本文へ必要最小限で追加する。

## 不足情報・補強ポイント

- 成人同士の合意、未成年利用の回避、インターネット異性紹介事業、個人情報保護の根拠リンクを自然に補強する。
- 無料アプリだけに頼るリスク、業者・詐欺・美人局など危険ユーザーの見分け方を維持・強化する。
- 下品・露骨な表現は避け、SEO記事として読みやすい文体に整える。

## 内部リンク候補

- 元記事内のアンカーリンクを維持する。
- 既存のアフィリエイトリンク・詳細リンクは原則維持し、本文内で不自然な変更をしない。

## 公的・信頼性のある外部リンク候補

- e-Gov法令検索（インターネット異性紹介事業の規制関連）
- 個人情報保護委員会（個人情報保護に関する一般的な根拠）
- 警察庁または公的機関のサイバー犯罪・相談窓口系ページ

## アフィリエイト導線の改善案

- おすすめアプリ比較表後に、読者が目的別に選びやすい導線を維持する。
- PCMAX、ワクワクメール、Jメールなど既存の主要導線は残す。
- 煽りすぎず、安全性・目的一致・料金確認を踏まえた自然なCTAにする。

## SWELL装飾の改善案

- 「この記事でわかること」はcapboxとして維持する。
- 比較表はcapboxの外、完全に閉じた直後に配置する。
- 重要な注意点・結論には既存マーカーを活かしつつ過剰装飾を避ける。

## リライト時の注意点

- 元記事より本文文字数を減らさない。
- 空H2/H3、数字だけ違う量産見出し、同じH3の繰り返しを作らない。
- 「サービスサービス」「必要ことです」「注意ことです」など不自然な日本語を残さない。
- 認証情報やWordPressユーザー名、アプリケーションパスワードを出力・記録しない。
